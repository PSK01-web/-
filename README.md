# 🔥 온애정 추어탕 상세페이지

> 몸의 온기를 채우는 가장 따뜻한 시간

## 📋 프로젝트 개요

온애정 추어탕의 제품 상세페이지입니다. 따뜻함과 과학적 신뢰성을 동시에 전달하는 디자인으로 제작되었습니다.

### 🎯 핵심 특징

- **과학적 근거**: 12편의 학술 논문 인용 (총 9,068회 인용)
- **3단계 온기 메커니즘**: 발생 → 흐름 → 유지
- **투명한 성분 공개**: 19가지 원료 100% 공개
- **미세 분말화 기술**: 흡수율 향상 기술 설명
- **인터랙티브 디자인**: 스크롤 애니메이션 및 동적 효과

## 📄 페이지 섹션

### 1️⃣ 인트로 (Intro)
- 어두운 배경에 따뜻한 그라데이션
- 김이 모락모락 나는 효과 (Steam Effect)
- 브랜드 네임 강조
- 스크롤 인디케이터

### 2️⃣ 건강 정보 (Health Info)
- 온기 3단계 메커니즘 다이어그램
- 노화와 대사에 관한 과학적 사실
- 논문 인용 박스 (2편)

### 3️⃣ 온애정 솔루션 (Solution)
**STEP 1: 발생 (Thermogenesis)**
- 생강, 마늘, 고추
- 생강 진저롤 논문

**STEP 2: 흐름 (Circulation)**
- 제주 참쑥, 들기름
- 들기름 오메가-3 논문

**STEP 3: 유지 (Retention)**
- 남원 미꾸라지, 사골
- 단백질 DIT 논문

### 4️⃣ 기술력 (Technology)
- 미세 분말화 기술 설명
- 흡수율 관련 논문 (2편)
- 4가지 핵심 원료 파우더
- 효과 시각화 (소화 부담 DOWN ↓, 체내 흡수 UP ↑)

### 5️⃣ 신뢰와 투명성 (Transparency)
- 시제품 vs 온애정 비교
- 19가지 성분 완전 공개
- 3가지 카테고리 분류
  - 힘의 원천 (Main Body)
  - 온기 파우더 (Absorb Powder)
  - 맛의 밸런스 (Flavor Balance)

### 6️⃣ 아웃트로 (Outro/CTA)
- 습관 메시지
- CTA 버튼 (온애정 시작하기)
- 따뜻한 분위기 배경

### 7️⃣ 부록
- 참고 논문 전체 리스트 (12편)
- 법적 고지사항
